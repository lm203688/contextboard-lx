ContextBoard Privacy Policy

Last updated: 2026-11-20

1. What we collect

ContextBoard does not collect any personal data or usage telemetry. All operations happen locally on your machine.

The only network call occurs when you activate a Pro license key against our verification endpoint (snapmark-license.61960005.workers.dev). This transmits only the license key string (a short alphanumeric token); our backend validates it and returns a boolean. No other data is sent.

2. What data we store

All contexts you create are stored in VS Code's local globalState — a JSON object kept on your device. Each context records:

  • Name — the label you chose.
  • CWD — the filesystem path of the workspace root at save time (stored as a plain string).
  • Git branch — result of git rev-parse --abbrev-ref HEAD run locally (no remote query).
  • Open files — absolute file paths of visible editors at save time.
  • Note — optional text you add when editing.

We do not create any files outside VS Code's standard data directories, and we never upload context data anywhere.

3. Third-party services

  • Paddle Billing — processes payment for the Pro upgrade. See the Paddle Privacy Policy.
  • Cloudflare Workers + KV — hosts the license verification API at snapmark-license.61960005.workers.dev. Cloudflare's standard logging applies to this endpoint. License keys are stored in Cloudflare KV (marked expired on cancellation, not deleted).

There is no third-party analytics, advertising, or tracking within ContextBoard.

4. Data retention

Since no user data leaves your machine, there is nothing for us to retain. The license verification log may contain the timestamp of your last request; this is not linked to your identity and is used solely for operational monitoring.

5. Contact

For privacy-related questions, email privacy@lxstudio.dev.

6. Changes

We may update this policy. Continued use after changes constitutes acceptance of the new terms.
